# API domain foundation notes

This directory preserves API-era domain foundation documents. Some describe
planned or historical implementation vocabulary and may predate the current
eleven-context API structure. They are useful as implementation history, not
as current Product or Domain authority.

Use the [Nexa Blueprint](https://github.com/nexa-suite/blueprint) for accepted
Product meaning, strategic bounded contexts and canonical architecture.
Nothing in this directory was deleted or promoted to current authority by the
API structural reorganization.
