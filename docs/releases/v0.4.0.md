# Nexa API v0.4.0

## Scope

Read-only Catalog Management query contract backed by the checksum-validated 50-item seed. The modern API remains database-free and deny-by-default.

## Contract

- `GET /api/v1/catalog-items`
- `GET /api/v1/catalog-items/{catalogItemId}`
- Bounded `q`, `brand`, `category`, `coldChain`, `page`, `size`, `sort` and `direction` parameters.
- Explicit summary/detail DTOs with money and media objects; no stock, promotion, tenant or workspace fields.

## Validation

- Maven tests: 44 passed.
- Springdoc local profile: OpenAPI `3.1.0`, two catalog paths.
- Docker modern profile: API, Platform and Portal images built and containers healthy.
- Playwright smoke: Platform `/overview` and Portal `/home` served successfully.

## Boundary

Anonymous catalog access is `401`; authenticated access without an approved authorization rule is `403`. Health/info are public. PostgreSQL, JPA, tenant identity and persistence are not part of this release.
