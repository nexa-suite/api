# v1.1.0-alpha.1 — source checkpoint prerelease

This prerelease preserves the current implementation checkpoint. It is a source snapshot, not a stable release, verified deployment or production-ready package. No signed application binary is attached.

## Evidence and limitations

`./mvnw -DskipTests test-compile` passed after repairing an incomplete test-fixture expression. This compiles production and test source; it does not execute tests. The earlier full integration run was interrupted and had failures. Physical Tenant fixture adaptation and wallet refund implementation remain incomplete.

Source implements or prepares Tenant-scoped suite contracts, explicit context boundaries and client workflows. Remaining construction, local two-Tenant provisioning/isolation, end-to-end intercommunication, final security/CI gates and distribution signing must be completed before the stable minor release. Refund policy is accepted but its complete backend and client workflow is not part of this checkpoint.

The following work continues on feature branches from this tagged source. Stable versions and later patches must describe their own verified scope; this checkpoint does not assert that the remaining work is only testing or patch-compatible.
