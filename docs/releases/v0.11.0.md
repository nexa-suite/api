# Nexa API v0.11.0

## Summary

PRE-V1 Architecture & Governance Foundation milestone for the Nexa API modular monolith.

## Included baseline

- Customer & Buyer Relationships boundary extraction and dedicated query capabilities.
- Tenant and Workspace governance invariants (single workspace, exactly-one Company Owner).
- Token revocation and session invalidation on tenant state changes.
- Purchase Request expiry persistence foundation (`expires_at` UTC timestamping).
- Public application contracts between business capabilities with Spring Modulith architecture enforcement.
- Row-Level Security (RLS) scoping and PostgreSQL concurrency controls.

## Known limitations

- Commercial Commitment currently uses warehouse reservation backing; canonical independent Inventory Reservation and Credit & Receivables separation are scheduled for subsequent construction waves.
- This milestone does not represent Nexa V1 functional completion or Production Readiness.

## Validation

- Clean build, 398 unit/integration/architecture tests passed (105 profile-dependent skips).
- Flyway fresh and upgrade migration validation passed.
- Architecture fitness (ArchUnit / Modulith) verified.
- CodeQL, container and security-load gates passed.
