# Nexa API v0.21.1

**Status:** published patch release.

This release provides runtime-configurable Swagger UI and OpenAPI contract support for cloud environments (Render) under the `s3` profile without weakening production database or session security boundaries.

## Scope

- v0.21.0 remains immutable history; this release is a surgical compatibility and operational patch.
- Enable Swagger UI (`/swagger-ui/**`, `/swagger-ui.html`) and OpenAPI docs (`/v3/api-docs/**`) via configurable runtime property `nexa.swagger.enabled` / `NEXA_SWAGGER_ENABLED=true` across non-local profiles.
- Keep default behavior disabled (`false`) unless explicitly enabled via environment configuration.
- Retain existing `local` profile defaults where Swagger UI and OpenAPI contracts remain enabled out-of-the-box.
- Adjust Content Security Policy (CSP) headers when Swagger UI is enabled to permit inline script and styling required by Swagger UI bundle execution.
- Maintain strict database least-privilege runtime, session authentication and origin boundaries across cloud and local runtimes.

## Configuration

In Render or container runtime environments:
- Set `NEXA_SWAGGER_ENABLED: "true"` to expose `/swagger-ui/index.html` and `/v3/api-docs`.
- Setting `NEXA_SWAGGER_ENABLED: "false"` or omitting it retains strict 401/denyAll security boundaries.

## Version and metadata boundary

- Maven, Render declarative configuration and the committed OpenAPI document report version `0.21.1`.
- OpenAPI schema compatibility with published v0.20.0 and earlier baselines is maintained.
