# Nexa API v3.0.2

ICISA can opt in to the existing Buyer checkout, Sales conversion, Warehouse
preparation, Driver delivery and Buyer receipt commands on the cloud profile.
This release also restores Buyer credit and scoped Operations reads. It keeps
the existing API contract and database schema.

## Deployment

Retain the verified Tenant binding and restricted roles. Use the
[cloud routing guide](../../ops/tenant-business-database-cloud.md) to rehearse
checkout and fulfillment before activating each route. Firebase Cloud Messaging
uses the existing dedicated worker and scope reader. Keep notification routing
limited to the approved events and eligible recipients.

## Verification

The integration suite follows one order from a Buyer draft to a sealed proof
of delivery in PostgreSQL. It checks the assigned Warehouse and Driver, rejects
unauthorized access and verifies that retrying the receipt returns the original
result. Separate tests cover Buyer credit, delivery loads and the notification
worker's scoped database access.
