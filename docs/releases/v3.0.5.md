# Nexa API v3.0.5

Buyer can manage personal addresses and exchange messages with the assigned
Sales user. During an active delivery, Buyer can see the driver’s latest
shared point for up to two minutes.

Enable cloud messaging and delivery location in Render using the settings in
the [cloud guide](../../ops/tenant-business-database-cloud.md). This release
uses the existing Buyer and Operations APKs and requires no database migration.
