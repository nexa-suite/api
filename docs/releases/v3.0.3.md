# Nexa API v3.0.3

This patch restores ICISA Buyer receivables, document and order summary
downloads, saved payment method reads, wallet balance and bank transfer
reporting. Operations gains scoped Sales and Warehouse routes for the
existing mobile flows, including document access for assigned Sales accounts.
Buyer live updates resume through the existing authenticated change feed.
The API contract and database schema are unchanged.

## Deployment

Retain the existing verified cloud database bindings and route flags. Enable
`NEXA_TENANT_BUSINESS_CLOUD_FIELD_VISITS_ENABLED=true` to include Sales visits.
The [cloud routing guide](../../ops/tenant-business-database-cloud.md) describes
permissions and rollout checks. After deployment, use the existing ICISA test
accounts to verify Buyer and Operations against the public API.

## Verification

PostgreSQL integration tests verify Buyer document and export access, reject
access outside the Buyer account, check Warehouse grants on transfer lists
and cover field visit version checks and idempotency. Buyer stream tests verify
account-scoped replay, heartbeats and session revocation.
