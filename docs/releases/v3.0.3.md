# Nexa API v3.0.3

Buyer can open receivables, read the wallet balance and saved payment methods,
report bank transfers, and download documents and order summaries. Order updates
again arrive through the authenticated change feed.

In Operations, Sales can open documents for assigned customers and use offer,
credit, direct order, and visit routes. Warehouse can read receiving zones,
inbound receipts, and transfer history. The patch also fixes overlapping text
in order summary PDFs.

The HTTP contract and database schema stay the same.

## Deployment

Keep the existing cloud database bindings and route flags. Set
`NEXA_TENANT_BUSINESS_CLOUD_FIELD_VISITS_ENABLED=true` to include Sales visits.
See the [cloud routing guide](../../ops/tenant-business-database-cloud.md) for
permissions and rollout checks. After deployment, sign in to Buyer and
Operations with the ICISA test accounts and check the screens listed above.

## Verification

PostgreSQL integration tests cover access to Buyer downloads, assigned Sales
accounts, Warehouse transfer grants, and field visit version checks and retries.
Change feed tests cover account-scoped replay, heartbeats, and closing a stream
when its session is revoked.
