# Nexa API v1.0.0

## Summary

V1 functional convergence baseline for the current modular API runtime.

## Included baseline

- Current Purchase Request and Sales Order continuation foundations.
- Tenant-safe identity, catalog, warehouse, logistics, payments and document runtime foundations.
- Coherent Maven dependency baseline with current integration adapters.

## Boundary

This release does not claim complete fiscal workflows, provider production readiness, full business capability acceptance or mobile/V2 implementation.

## Validation

- API CI and integration verification passed.
- CodeQL, container and security-load gates passed.
