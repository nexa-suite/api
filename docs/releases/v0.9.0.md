# Nexa API v0.9.0

Released: 2026-08-18

## Summary

Operations stabilization for the consolidated commercial, Warehouse and Logistics baseline.

## Fixed

- Sales Order creator identity, aggregate-owned lifecycle and concurrent conversion replay.
- Warehouse FEFO/expiration forward migration and route-start application ownership.
- Dispatch number initialization and OpenAPI release metadata.
- Refresh and workspace-preview context resolution now fail closed on ambiguous tenant/workspace slugs and use exact persisted membership when available.

## Added

- Public contact/demo request intake with validation, durable email/IP throttling, audit evidence and no automatic Tenant or identity provisioning.
- Forward-only Flyway hardening for direct tenant-scoped membership and manual sales-draft tables.
- Internal TASK-011 document-subject vocabulary and lookup contract only.

## Boundary

Business Documents, storage/evidence and Payments/Stripe technical foundations are present in the API runtime and database baseline. Product capability acceptance, final document lifecycle, fiscal/provider workflows and complete payment business semantics remain unclaimed.

## Validation

Local and remote technical validation passed. API CI, supply-chain, security/load and CodeQL completed successfully for this release.
