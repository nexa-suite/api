# Nexa API v3.0.4

Buyer can reopen a purchase request using the version returned by Render.
Draft responses tell intermediaries to preserve that version header.

Catalog favorites are available in the cloud profile when
`NEXA_TENANT_BUSINESS_CATALOG_FAVORITES_ENABLED` is enabled alongside the
existing cloud catalog read switches. The API stores favorites for the signed-in
Buyer membership in the existing business database.

There are no database migrations. The OpenAPI contract changes only its
version.
