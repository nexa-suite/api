# Nexa API v0.8.0

## Summary

Consolidated TASK-NEXA-008, TASK-NEXA-008.6, TASK-NEXA-009, TASK-NEXA-010 and TASK-NEXA-010.5 into the commercial, warehouse and logistics API baseline.

## Highlights

- Application-owned Purchase Request to Sales Order conversion, lifecycle, idempotency and secure Change Feed.
- Warehouse topology, lots, movements, FEFO reservations, readiness and atomic reservation consumption.
- Dispatch creation, preparation, assignment, scheduling, route readiness/start, temperature incidents, reprogramming and POD metadata.
- Buyer delivery tracking with client-account-safe projections.

## Validation

- `./mvnw clean verify -Dnexa.integration.enabled=true`: 122 tests passed, 0 failed, 0 skipped.
- Fresh PostgreSQL migrations V1 through V21, restart and Flyway validation passed.
- Runtime OpenAPI 3.1.0 and tracked static OpenAPI contain the same 82 paths.
- Canonical Modern Docker source build passed with API, Platform, Portal and PostgreSQL healthy.

## Boundary

POD metadata is implemented. Evidence-file storage, business documents, invoices, payments, SUNAT and Kafka remain reserved for TASK-NEXA-011 or later.
